# 🎬 DMM (FANZA同人・アニメ) セール×人気自動巡回・投稿設定 (targets.md)

本タスクは毎週水曜22時および毎週土曜5時に起動し、DMM(FANZA)の同人・アニメジャンルから「人気ランキング上位かつ現在セール中」の注目作品を全自動抽出し、豪華①〜⑦構成の記事を生成・投稿します。

---

## 1. FANZA同人 (デジタル同人) ターゲット
- **フロア**: `doujin` (FANZA同人 / ボイス / 同人ゲーム / 同人誌)
- **選定条件**: 人気順 × 現在セール割引中 (`is_discount`)
- **ターゲット取得件数**: 1〜2件

## 2. FANZAアニメ (デジタルアニメ) ターゲット
- **フロア**: `anime` (FANZAアニメ動画)
- **選定条件**: 人気順 × 現在セール割引中 (`is_discount`)
- **ターゲット取得件数**: 1〜2件

---

## 3. 生成記事の構成テンプレート
1. キャッチコピー付きタイトル
2. 大判アイキャッチ画像 ＋ セール割引バッジ（元値・セール価格・割引率）
3. 出演女優 / 声優 / サークル名のプロフィールカード
4. ⚡ 30秒でわかる3行スッキリ要約
5. ⭐️ 購入者の評価・リアルな口コミ評判 (★4.5/5.0)
6. 📖 ストーリー・詳細あらすじ解説
7. 🖼 サンプル画像ギャラリー / サンプル動画埋め込み
8. 公式アフィリエイトボタン
